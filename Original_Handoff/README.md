- Existing logo should be sourced from the actual product/brand repository; generated logo in concept art is not authoritative.
- Sample trading volumes, user counts, battle matchups, season, rewards, rankings and trend percentages in V2 mockup are **illustrative placeholders only**.
- Colors below are provisional visually estimated values, not verified brand design tokens.
- Avoid assuming live battle, guild recommendations or other features have production APIs without checking the repository.
- Do not change existing business logic, compliance disclaimers, wallet behavior or fee/reward formulas for aesthetic reasons.
